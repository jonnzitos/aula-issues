O que é HTML?

Conhecendo a linguagem de marcação da web

HTML (HyperText Markup Language) é uma linguagem de marcação utilizada para estruturar páginas da web. Por meio de suas tags, podemos adicionar textos, imagens, links, vídeos e diversos outros elementos a um site.
